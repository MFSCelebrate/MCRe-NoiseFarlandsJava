# 🔗 项目路线图

本文档概述了 MCRe-NoiseFarlandsJava 的未来更新路线，此列表受社区和改版进展动态调整。  
长短期计划中的功能列表顺序不为更新新功能的先后顺序。

### 🎬 短期计划

#### 🤔 新功能

- 修改噪声第二次采样坐标比例
    - 1.18 加入的新噪声和数据包自定义的噪声在每个采样点都会采样两次，一次在原采样坐标，另一次则在原采样坐标乘以一个比例系数（默认为
      1.0181268882175227）之处，以防止噪声生成可见的重复地形。此功能将提供一个输入框，用户可以自定义第二次采样坐标比例。
      
- 修改柏林噪声平滑插值函数
    - 柏林噪声生成的其中一步是对噪声进行平滑插值，也就是把当前值带入到一个插值函数中（默认为 `6t^5 - 15t^4 + 10t^3`
      ）来确保生成的噪声平滑。此功能将提供一个输入框，用户可以通过输入表达式自定义这个插值函数（届时还将引入 `exp4j`
      库来解析表达式）。
      
- 扩展基岩版低噪声值容量至高噪声值容量
    - 单精度浮点数不仅精度较低，容量相比双精度浮点数也很有限，这导致基岩版边缘之地和“虚无”的生成大幅提前。这两个限制（低精度和低容量）在基岩版是同时存在的，但我们可以扩展噪声值容量至双精度浮点数，以此来探索基岩版的后几层边境。
    
- 将调试屏幕中过大的数值显示为科学计数法 (部分已实现)
    - 针对坐标和 Noise Router 中可能因噪声溢出产生极端巨大的数值，显示为按 `E` 表示的科学计数法数值。
    
- 修复拼图方块远距离故障
    - 当 X/Z 超过 ±1073741824 时，拼图方块会因除法平均数溢出而停止工作，导致所有依赖于拼图方块的结构被破坏。开启此选项将修复此问题。
    
- 修复因视锥体无效导致的卡死
    - 当玩家的任意坐标在 `float` 中为非有限值，或在Y坐标大到一定程度时俯仰角超过40°左右，会导致游戏客户端卡死。开启此选项将修复此问题。
    
- 修复Y坐标整数极限外渲染实体卡死
    - 当玩家的Y坐标超过 ±2147483647 时，渲染任何实体将导致游戏客户端卡死。开启此选项将修复此问题。
    
- 更改混合噪声平面比例
    - 混合噪声（密度函数 `minecraft:old_blended_noise`）会在采样时将坐标乘以一个特定的、硬编码的常量系数，即此处的平面比例。此选项将提供几个输入框，允许用户修改这些常量。
    
- 解除命令中浮点参数输入限制
    - 原版中浮点数类命令参数不允许玩家输入按 `E` 表示的科学计数法数值、`Infinity` 和 `NaN` 等特殊值。开启此选项将解除此限制。
    
- 一键复制地形坐标
    - 通过指令或快捷键，复制当前地形坐标到剪贴板，方便粘贴到其他位置中。
    
- 禁用指定噪声
    - 将在配置中添加一个字符串数组，用户可以填写噪声 ID，这些噪声将在采样时返回 0。
    
- 新交互式计算器：噪声信息
    - 输入一个噪声 ID 或定义，计算并显示噪声的详细信息（值域、频率、溢出位置等）。
    
- 新交互式计算器：浮点数分析
    - 输入一个浮点数，选择精度，分析显示其二进制表示、相邻可表示数、精度、数学精确值、整数舍入范围等。对于研究与浮点数精度损失有关的距离现象时非常有用。
    
- 修复远距离处降雪精度损失
    - 由于 [MC-192718[↗]](https://bugs.mojang.com/browse/MC/issues/MC-192718)
      ，温度在世界远处因浮点数精度损失而无法正常运作，导致积雪和冰块生成得棱角分明。开启此选项将修复此问题。
      
- 修复远距离处声音精度损失
    - 由于 [MC-191170[↗]](https://bugs.mojang.com/browse/MC/issues/MC-191170)，在远距离处，声音会从错误的地方发出，且有可能会突然停止。在
      X/Z 达到 ±268,435,456 后变得越来越严重，许多声音会越来越听不见。开启此选项将修复此问题。
      
- 兼容原版/插件服务端
    - 由于改版修改了网络配置层发包，导致在进服时会出现 `[09:52:33] [Netty NIO IO #3/DEBUG]: Failed to sent packet` 报错，未来会修复这个问题。

- 支持 Fabric API，让改版有加入自定义模组的可能
    - 改版虽然支持 Fabric Loader 0.19.5的加载，但是不能加载与改版源码冲突的Mod，例如Fabric API (会因为 Mixin 注入失败崩溃)
    
#### 🚄 优化

- 尽可能将区块生成优化到极点，修复在区块生成时掉帧的问题

### 🕋 中期计划

- 修复坐标超过 33554432 时出现的一系列 Bug
    - 已知的包括：温度覆盖出现精度丢失，调试渲染器出现精度丢失等问题
    
- 阻止游戏在区块生成失败时崩溃
    - 开启后，如果在生成区块时出现错误，游戏会像区块读取失败那样在右上角显示弹窗并继续运行，而不是直接崩溃。

### 🕕 长期计划

- 在世界界限方面突破32位整数限制、64位整数限制、单精度浮点数乃至双精度浮点数的限制。
